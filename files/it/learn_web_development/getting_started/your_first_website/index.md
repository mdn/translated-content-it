Questo modulo introduce agli aspetti pratici dello sviluppo web. Verranno raccolte le risorse e scritto il codice per creare una semplice pagina web, che verrà poi pubblicata affinché tutti possano visualizzarla.

Creare un sito web professionale richiede molto lavoro, quindi, per chi è alle prime armi con lo sviluppo web, è consigliabile iniziare in piccolo. Non verrà creato subito un altro Facebook, ma non è difficile realizzare online un semplice sito web personale, quindi si inizierà da qui.

## Prerequisiti

Questo modulo non presuppone alcuna conoscenza precedente delle tecnologie web, ma richiede già dimestichezza con l'uso del sistema operativo, incluso l'utilizzo del file system e la navigazione sul web. Devono essere installati un editor di codice e più browser web.

In caso contrario, si consiglia di seguire prima il modulo [Configurazione dell'ambiente](/it/docs/Learn_web_development/Getting_started/Environment_setup).

## Tutorial

- [Che aspetto avrà il tuo sito web?](/it/docs/Learn_web_development/Getting_started/Your_first_website/What_will_your_website_look_like)
  - : Prima di iniziare a scrivere il codice per il sito web, è opportuno pianificarlo. Quali informazioni verranno mostrate? Quali font e colori verranno utilizzati? Qui viene illustrato un semplice metodo da seguire per pianificare i contenuti e il design del sito.

- [Creazione dei contenuti](/it/docs/Learn_web_development/Getting_started/Your_first_website/Creating_the_content)
  - : HTML (**H**yper**T**ext **M**arkup **L**anguage) è il codice utilizzato per strutturare una pagina web e i suoi contenuti. Ad esempio, i contenuti possono essere strutturati in un insieme di paragrafi, un elenco puntato oppure utilizzando immagini e tabelle di dati. Questo articolo fornisce una comprensione di base di HTML e delle sue funzioni e mostra come creare i contenuti di base per il primo sito web.

- [Applicazione di stili ai contenuti](/it/docs/Learn_web_development/Getting_started/Your_first_website/Styling_the_content)
  - : CSS (Cascading Style Sheets) è il codice che applica stili ai contenuti web. _Applicazione di stili ai contenuti_ illustra ciò che serve per iniziare. Verranno fornite risposte a domande come: Come rendere rosso il testo? Come visualizzare i contenuti in una determinata posizione nel layout della pagina web? Come decorare la pagina web con immagini e colori di sfondo?

- [Aggiunta di interattività](/it/docs/Learn_web_development/Getting_started/Your_first_website/Adding_interactivity)
  - : JavaScript è un linguaggio di programmazione che aggiunge interattività ai siti web. Ciò avviene nei giochi, nel comportamento delle risposte alla pressione dei pulsanti o nell'immissione di dati nei moduli, negli stili dinamici, nelle animazioni e così via. Questo articolo aiuta a iniziare con JavaScript e ad approfondire la comprensione di ciò che è possibile fare.

- [Pubblicazione del sito web](/it/docs/Learn_web_development/Getting_started/Your_first_website/Publishing_your_website)
  - : Una volta terminata la scrittura del codice e l'organizzazione dei file che compongono il sito web, è necessario pubblicare tutto online affinché le persone possano trovarlo. Questo articolo spiega come pubblicare online il sito web di esempio con poco sforzo.
