I nostri **moduli fondamentali** trattano argomenti sui quali riteniamo che ogni sviluppatore web debba avere una buona preparazione. Ciò include tutte le informazioni necessarie per progettare e creare un'app web di base e accessibile, che segua le moderne best practice, nonché per gestire e distribuire il codice usando strumenti appropriati.

## Prerequisiti

Sebbene non siano richieste conoscenze preliminari per iniziare questa serie di moduli, è consigliabile acquisire familiarità con il proprio computer, assicurarsi di avere installato un insieme di applicazioni necessarie (come browser web e un editor di codice) e fare qualche lettura introduttiva sul web e sulle tecnologie web, se non è già stato fatto. Tutti questi argomenti sono trattati nei nostri [moduli introduttivi](/it/docs/Learn_web_development/Getting_started).

In particolare, se non è mai stata scritta alcuna riga di codice, consigliamo il modulo [Il tuo primo sito web](/it/docs/Learn_web_development/Getting_started/Your_first_website), che introduce alle tecnologie web in modo molto graduale e guida attraverso il processo di creazione di un semplice sito web.

## Moduli

- [Strutturare i contenuti con HTML](/it/docs/Learn_web_development/Core/Structuring_content)
  - : Per creare un sito web di alta qualità, utilizzabile e accessibile, è necessario comprendere come definire la struttura dei contenuti usando HTML semantico. Questo modulo copre le basi del linguaggio HTML, prima di esaminare aree chiave come la struttura del documento, i link, gli elenchi, le immagini, i moduli e altro ancora.
- [Nozioni di base sullo stile CSS](/it/docs/Learn_web_development/Core/Styling_basics)
  - : CSS (Cascading Style Sheets) viene usato per definire lo stile e il layout delle pagine web, ad esempio per modificare il carattere, il colore, le dimensioni e la spaziatura dei contenuti, suddividerli in più colonne o aggiungere animazioni e altre caratteristiche decorative. Questo modulo fornisce tutte le basi di CSS necessarie per il momento, incluse sintassi, funzionalità e tecniche.
- [Stile del testo con CSS](/it/docs/Learn_web_development/Core/Text_styling)
  - : Dopo aver trattato le basi del linguaggio CSS, il successivo argomento CSS su cui concentrarsi è lo stile del testo, una delle attività più comuni svolte con CSS. Qui vengono esaminate nozioni fondamentali quali l'impostazione di carattere, grassetto, corsivo, spaziatura tra righe e lettere, ombre esterne e altre caratteristiche del testo. Il modulo si conclude esaminando l'applicazione di caratteri personalizzati alla pagina e lo stile di elenchi e link.
- [Layout CSS](/it/docs/Learn_web_development/Core/CSS_layout)
  - : Nei moduli precedenti è stato esaminato come definire lo stile e manipolare i riquadri che contengono i contenuti. Ora è il momento di vedere come disporre correttamente i riquadri l'uno rispetto all'altro e rispetto alla viewport del browser. Questo modulo tratta float, posizionamento, altri moderni strumenti di layout e la creazione di design responsivi che si adattano a dispositivi, dimensioni dello schermo e risoluzioni diversi.
- [Scripting dinamico con JavaScript](/it/docs/Learn_web_development/Core/Scripting)
  - : JavaScript è un argomento molto ampio, con numerose funzionalità, stili e tecniche da imparare, nonché molte API e strumenti costruiti su di esso. Questo modulo si concentra soprattutto sugli elementi essenziali del linguaggio principale, oltre ad alcuni argomenti circostanti fondamentali: impararli fornirà una solida base di partenza.
- [Framework e librerie JavaScript](/it/docs/Learn_web_development/Core/Frameworks_libraries)
  - : I framework JavaScript sono una parte essenziale dello sviluppo web front-end moderno e forniscono agli sviluppatori strumenti collaudati per creare applicazioni web interattive e scalabili. Molte aziende moderne usano i framework come parte standard della propria strumentazione, quindi molti lavori nello sviluppo front-end richiedono oggi esperienza con i framework. In questa serie di articoli, l'obiettivo è fornire un punto di partenza confortevole per iniziare a imparare i framework.
- [Accessibilità](/it/docs/Learn_web_development/Core/Accessibility)
  - : L'accesso a contenuti web come servizi pubblici, istruzione, siti di e-commerce e intrattenimento è un diritto umano. Nessuno dovrebbe essere escluso in base a disabilità, razza, posizione geografica o altre caratteristiche umane. Questo modulo discute le best practice e le tecniche da apprendere per rendere i siti web il più accessibili possibile.
- [Design per sviluppatori](/it/docs/Learn_web_development/Core/Design_for_developers)
  - : L'idea di questo modulo è (re)introdurre gli sviluppatori al design thinking. Potrebbero non voler lavorare come designer, ma avere alcune conoscenze di base sull'esperienza utente e sulla teoria del design è utile per chiunque sia coinvolto nella creazione di siti web, indipendentemente dal ruolo. Come minimo, anche lo sviluppatore più tecnico e "non designer" dovrebbe comprendere i brief di design, il motivo per cui le cose sono progettate come sono ed essere in grado di assumere la prospettiva dell'utente. Inoltre, contribuirà a migliorare l'aspetto dei portfolio.
- [Controllo di versione](/it/docs/Learn_web_development/Core/Version_control)
  - : Gli strumenti di controllo di versione sono una parte essenziale dei flussi di lavoro moderni, per eseguire backup e collaborare su codebase. Questo modulo guida attraverso gli elementi essenziali del controllo di versione usando Git e GitHub.
