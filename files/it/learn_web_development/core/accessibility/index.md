L'accesso ai contenuti web quali servizi pubblici, istruzione, siti di e-commerce e intrattenimento è un diritto umano. Nessuno dovrebbe essere escluso in base a disabilità, etnia, posizione geografica o altre caratteristiche umane. Questo modulo illustra le migliori pratiche e le tecniche da apprendere per rendere i siti web il più accessibili possibile.

## Prerequisiti

Prima di iniziare questo modulo, è necessario avere familiarità con [HTML](/it/docs/Learn_web_development/Core/Structuring_content), [CSS](/it/docs/Learn_web_development/Core/Styling_basics) e [JavaScript](/it/docs/Learn_web_development/Core/Scripting).

> [!NOTE]
> Se si lavora su un computer, tablet o altro dispositivo su cui non è possibile creare file, è possibile provare a eseguire il codice in un editor online come [CodePen](https://codepen.io/) o [JSFiddle](https://jsfiddle.net/).

## Tutorial e sfide

- [Che cos'è l'accessibilità?](/it/docs/Learn_web_development/Core/Accessibility/What_is_accessibility)
  - : Questo articolo avvia il modulo con un'analisi approfondita di cosa sia l'accessibilità: include i gruppi di persone da considerare e il motivo, gli strumenti che diverse persone usano per interagire con il web e come rendere l'accessibilità parte del flusso di lavoro di sviluppo web.
- [Strumenti per l'accessibilità e tecnologie assistive](/it/docs/Learn_web_development/Core/Accessibility/Tooling)
  - : Successivamente l'attenzione si concentra sugli strumenti per l'accessibilità, fornendo informazioni sui tipi di strumenti utilizzabili per aiutare a risolvere i problemi di accessibilità e sulle tecnologie assistive usate dalle persone con disabilità durante la navigazione sul web. Questi strumenti verranno usati negli articoli successivi.
- [HTML: una buona base per l'accessibilità](/it/docs/Learn_web_development/Core/Accessibility/HTML)
  - : Gran parte dei contenuti web può essere resa accessibile semplicemente assicurandosi di usare sempre gli elementi HTML corretti per lo scopo corretto. Questo articolo analizza in dettaglio come HTML possa essere usato per garantire la massima accessibilità.
- [Migliori pratiche di accessibilità per CSS e JavaScript](/it/docs/Learn_web_development/Core/Accessibility/CSS_and_JavaScript)
  - : CSS e JavaScript, se usati correttamente, possono anche consentire esperienze web accessibili, ma se usati impropriamente possono compromettere significativamente l'accessibilità. Questo articolo illustra alcune migliori pratiche per CSS e JavaScript da considerare per assicurare che anche i contenuti complessi siano il più accessibili possibile.
- [Nozioni di base su WAI-ARIA](/it/docs/Learn_web_development/Core/Accessibility/WAI-ARIA_basics)
  - : Proseguendo dall'articolo precedente, talvolta può essere difficile creare controlli UI complessi che coinvolgono HTML non semantico e contenuti dinamici aggiornati con JavaScript. WAI-ARIA è una tecnologia che può aiutare con tali problemi aggiungendo ulteriore semantica che browser e tecnologie assistive possono riconoscere e usare per comunicare agli utenti ciò che sta accadendo. Qui verrà mostrato come usarla a un livello di base per migliorare l'accessibilità.
- [Contenuti multimediali accessibili](/it/docs/Learn_web_development/Core/Accessibility/Multimedia)
  - : Un'altra categoria di contenuti che può creare problemi di accessibilità è quella multimediale: ai contenuti video, audio e immagini devono essere fornite adeguate alternative testuali, affinché possano essere compresi dalle tecnologie assistive e dai relativi utenti. Questo articolo mostra come fare.
- [Accessibilità sui dispositivi mobili](/it/docs/Learn_web_development/Core/Accessibility/Mobile)
  - : Poiché l'accesso al web tramite dispositivi mobili è molto diffuso e piattaforme popolari come iOS e Android dispongono di strumenti di accessibilità completi, è importante considerare l'accessibilità dei contenuti web su queste piattaforme. Questo articolo esamina le considerazioni sull'accessibilità specifiche per i dispositivi mobili.
- [Risoluzione dei problemi di accessibilità](/it/docs/Learn_web_development/Core/Accessibility/Accessibility_troubleshooting) <sup>Sfida</sup>
  - : In questa sfida viene presentato un semplice sito con diversi problemi di accessibilità da diagnosticare e correggere.
