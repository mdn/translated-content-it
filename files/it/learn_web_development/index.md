- Creato dalla community MDN e perfezionato grazie ai contributi di studenti, docenti e sviluppatori della più ampia community web.

- Progettato per portare da "principiante" a "a proprio agio" (non da "principiante" a "esperto"), fornendo conoscenze sufficienti per utilizzare risorse più avanzate (come [il resto di MDN](/en-US/)).

## Metti alla prova le tue competenze

Nel corso troverai diversi articoli progettati per aiutare a valutare se sono stati compresi gli argomenti insegnati. Esistono due tipi:

- Gli articoli "Metti alla prova le tue competenze" sono più frequenti e verificano la conoscenza di una singola funzionalità isolata, come i link HTML, il box model CSS o le funzioni JavaScript.
- Le "Sfide" sono meno frequenti e verificano la capacità di usare insieme più funzionalità per creare un sito web completo o un programma di qualche tipo.

La maggior parte delle domande include blocchi di codice HTML/CSS/JavaScript che mostrano il codice iniziale per ciascuna attività. Il modo consigliato per completarle è premere il pulsante **"Play"** in uno dei blocchi di codice per aprire l'esempio nel [MDN Playground](/en-US/play), quindi modificare il codice in base alle istruzioni della domanda.

Se viene commesso un errore, è possibile cancellare il proprio lavoro usando il pulsante Reset nel MDN Playground. Se si è davvero bloccati, è possibile (di solito) visualizzare la soluzione alla fine di ogni sezione della domanda oppure [chiedere aiuto](#contattaci).

> [!NOTE]
> Se si preferisce lavorare nel proprio editor o in un editor online, come [CodePen](https://codepen.io/) o [JSFiddle](https://jsfiddle.net/), è possibile copiare il codice dal MDN Playground nell'ambiente scelto.

Alcune domande non includono blocchi di codice iniziali e chiedono invece di scaricare file iniziali su cui lavorare sul computer locale. Talvolta ciò è dovuto alla natura complessa della domanda, mentre altre volte è semplicemente un modo per variare un po'.

## Ottenere i nostri esempi di codice

Gli esempi di codice presenti nell'area di apprendimento sono tutti [disponibili su GitHub](https://github.com/mdn/learning-area/):

- Il modo più semplice per ottenerli è [scaricare un file ZIP dell'ultimo branch di codice principale](https://codeload.github.com/mdn/learning-area/zip/main).
- Se si ha familiarità con Git e GitHub, è possibile anche scegliere di clonare il repository.

Siamo più che felici di parlare con chiunque, sia esso uno studente, un docente, uno sviluppatore web esperto o chiunque altro sia interessato a migliorare l'esperienza di apprendimento.
