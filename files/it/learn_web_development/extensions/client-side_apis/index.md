Le **Application Programming Interfaces** (**API**) sono funzionalità di programmazione per manipolare diversi aspetti del browser e del sistema operativo su cui viene eseguito il sito, oppure per manipolare dati provenienti da altri siti web o servizi. Questo modulo tratta aspetti comuni di alcune delle classi più diffuse di API Web che non sono state precedentemente affrontate in dettaglio, fornendo una base utile per chi desidera approfondire l'uso delle API del browser.

## Prerequisiti

Prima di iniziare questo modulo, è necessario aver appreso i fondamenti di [JavaScript](/it/docs/Learn_web_development/Core/Scripting), in particolare i [fondamenti degli oggetti JavaScript](/it/docs/Learn_web_development/Core/Scripting/Object_basics) e gli argomenti principali sulle API, come lo [scripting del DOM](/it/docs/Learn_web_development/Core/Scripting/DOM_scripting) e le [richieste di rete](/it/docs/Learn_web_development/Core/Scripting/Network_requests).

Sarebbe inoltre utile avere una certa familiarità con [HTML](/it/docs/Learn_web_development/Core/Structuring_content) e [CSS](/it/docs/Learn_web_development/Core/Styling_basics).

> [!NOTE]
> Se si lavora su un computer, tablet o altro dispositivo su cui non è possibile creare file, si può provare a eseguire il codice in un editor online come [CodePen](https://codepen.io/) o [JSFiddle](https://jsfiddle.net/).

## Tutorial

- [Introduzione alle API web](/it/docs/Learn_web_development/Extensions/Client-side_APIs/Introduction)
  - : Per iniziare, esamineremo le API a un livello generale: cosa sono, come funzionano, come vengono usate nel codice e come sono strutturate? Vedremo inoltre le diverse classi principali di API e i tipi di utilizzo che hanno.
- [API video e audio](/it/docs/Learn_web_development/Extensions/Client-side_APIs/Video_and_audio_APIs)
  - : HTML include elementi per incorporare contenuti multimediali avanzati nei documenti — {{htmlelement("video")}} e {{htmlelement("audio")}} — che a loro volta dispongono di API per controllare la riproduzione, cercare posizioni specifiche e così via. Questo articolo mostra come svolgere attività comuni, come creare controlli di riproduzione personalizzati.
- [Disegnare grafica](/it/docs/Learn_web_development/Extensions/Client-side_APIs/Drawing_graphics)
  - : Il browser contiene alcuni strumenti molto potenti per la programmazione grafica, dal linguaggio Scalable Vector Graphics ([SVG](/it/docs/Web/SVG)) alle API per disegnare sugli elementi HTML {{htmlelement("canvas")}} (vedere [l'API Canvas](/it/docs/Web/API/Canvas_API) e [WebGL](/it/docs/Web/API/WebGL_API)). Questo articolo fornisce un'introduzione all'API Canvas e ulteriori risorse per approfondire.
- [Archiviazione lato client](/it/docs/Learn_web_development/Extensions/Client-side_APIs/Client-side_storage)
  - : I moderni browser web offrono diverse tecnologie che consentono di memorizzare dati relativi ai siti web e recuperarli quando necessario, permettendo di conservare i dati a lungo termine, salvare i siti per l'uso offline e altro ancora. Questo articolo spiega i concetti fondamentali del loro funzionamento.
- [API di terze parti](/it/docs/Learn_web_development/Extensions/Client-side_APIs/Third_party_APIs)
  - : Le API trattate finora sono integrate nel browser, ma non tutte le API lo sono. Molti grandi siti web e servizi, come Google Maps, Facebook, PayPal e così via, forniscono API che consentono agli sviluppatori di utilizzare i loro dati o servizi (ad esempio, visualizzare Google Maps personalizzate sul proprio sito o utilizzare l'accesso tramite Facebook per autenticare gli utenti). Questo articolo esamina la differenza tra le API del browser e le API di terze parti e mostra alcuni usi tipici di queste ultime.
