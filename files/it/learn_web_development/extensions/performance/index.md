La creazione di siti web richiede HTML, CSS e JavaScript. Per creare siti web e applicazioni che le persone desiderano usare, capaci di attrarre e trattenere gli utenti, è necessario realizzare una buona esperienza utente. Parte di una buona esperienza utente consiste nel garantire che i contenuti si carichino rapidamente e rispondano alle interazioni dell'utente. Questo è noto come **prestazioni web** e in questo modulo verranno esaminati i fondamenti per creare siti web performanti.

Il resto del materiale didattico per principianti cerca di attenersi il più possibile alle buone pratiche del web, quali le prestazioni e l'[accessibilità](/it/docs/Learn_web_development/Core/Accessibility). Tuttavia, è utile concentrarsi specificamente anche su questi argomenti e assicurarsi di conoscerli bene.

## Prerequisiti

Sebbene la conoscenza di HTML, CSS e JavaScript sia necessaria per implementare molte raccomandazioni per migliorare le prestazioni web, sapere come creare applicazioni non è un prerequisito necessario per comprendere e misurare le prestazioni web. Prima di affrontare questo modulo, si consiglia tuttavia di acquisire almeno un'idea di base dello sviluppo web seguendo il modulo [Il tuo primo sito web](/it/docs/Learn_web_development/Getting_started/Your_first_website).

Sarebbe inoltre utile approfondire un po' questi argomenti, con moduli quali:

- [Strutturare i contenuti con HTML](/it/docs/Learn_web_development/Core/Structuring_content)
- [Nozioni di base sullo stile CSS](/it/docs/Learn_web_development/Core/Styling_basics)
- [Scripting dinamico con JavaScript](/it/docs/Learn_web_development/Core/Scripting)

## Guida

- [Il "perché" delle prestazioni web](/it/docs/Learn_web_development/Extensions/Performance/why_web_performance)
  - : Questo articolo illustra perché le prestazioni web sono importanti per l'accessibilità, l'esperienza utente e gli obiettivi aziendali.
- [Cosa sono le prestazioni web?](/it/docs/Learn_web_development/Extensions/Performance/What_is_web_performance)
  - : È noto che le prestazioni web sono importanti, ma cosa le determina? Questo articolo introduce i componenti delle prestazioni, dal caricamento e rendering delle pagine web, incluso il modo in cui i contenuti arrivano nel browser degli utenti per essere visualizzati, fino ai gruppi di persone da considerare quando si pensa alle prestazioni.
- [Come percepiscono le prestazioni gli utenti?](/it/docs/Learn_web_development/Extensions/Performance/Perceived_performance)
  - : Più della velocità effettiva del sito web in millisecondi, conta la velocità con cui gli utenti percepiscono il sito. Queste percezioni sono influenzate dal tempo effettivo di caricamento della pagina, dall'inattività, dalla reattività all'interazione dell'utente e dalla fluidità dello scorrimento e di altre animazioni. In questo articolo vengono discussi i vari parametri di caricamento, animazione e reattività, insieme alle buone pratiche per migliorare la percezione dell'utente, se non le tempistiche effettive.
- [Misurare le prestazioni](/it/docs/Learn_web_development/Extensions/Performance/Measuring_performance)
  - : Ora che sono stati compresi alcuni parametri delle prestazioni, viene approfondito l'uso degli strumenti, dei parametri e delle API per le prestazioni, oltre a come rendere le prestazioni parte del flusso di lavoro dello sviluppo web.
- [Multimedia: immagini](/it/docs/Learn_web_development/Extensions/Performance/Multimedia)
  - : L'ottimizzazione dei media è spesso l'intervento più semplice per migliorare le prestazioni web. È possibile fornire file multimediali diversi in base alle capacità, alle dimensioni e alla densità di pixel di ciascun user agent. In questo articolo vengono discussi l'impatto delle immagini sulle prestazioni e i metodi per ridurre il numero di byte inviati per immagine.
- [Multimedia: video](/it/docs/Learn_web_development/Extensions/Performance/video)
  - : L'ottimizzazione dei media è spesso l'intervento più semplice per migliorare le prestazioni web. In questo articolo vengono discussi l'impatto dei contenuti video sulle prestazioni e suggerimenti quali la rimozione delle tracce audio dai video di sfondo, che può migliorare le prestazioni.
- [Ottimizzazione delle prestazioni JavaScript](/it/docs/Learn_web_development/Extensions/Performance/JavaScript)
  - : Se usato correttamente, JavaScript può consentire esperienze web interattive e coinvolgenti, oppure può danneggiare significativamente il tempo di download, il tempo di rendering, le prestazioni nell'applicazione, la durata della batteria e l'esperienza utente. Questo articolo illustra alcune buone pratiche JavaScript da considerare per garantire che anche i contenuti complessi siano il più performanti possibile.
- [Ottimizzazione delle prestazioni HTML](/it/docs/Learn_web_development/Extensions/Performance/HTML)
  - : Alcuni attributi e l'ordine delle sorgenti nel markup possono influire sulle prestazioni del sito web. Riducendo al minimo il numero di nodi DOM e assicurandosi di usare l'ordine e gli attributi migliori per includere contenuti quali stili, script, media e script di terze parti, è possibile migliorare drasticamente l'esperienza utente. Questo articolo esamina in dettaglio come utilizzare HTML per garantire le massime prestazioni.
- [Ottimizzazione delle prestazioni CSS](/it/docs/Learn_web_development/Extensions/Performance/CSS)
  - : CSS può essere un obiettivo di ottimizzazione meno importante per migliorare le prestazioni, ma alcune funzionalità CSS influiscono sulle prestazioni più di altre. In questo articolo vengono esaminate alcune proprietà CSS che influenzano le prestazioni e modalità consigliate per gestire gli stili, così da garantire che le prestazioni non siano influenzate negativamente.
- [Il caso aziendale per le prestazioni web](/it/docs/Learn_web_development/Extensions/Performance/business_case_for_performance)
  - : Uno sviluppatore può fare molte cose per migliorare le prestazioni, ma quanto deve essere veloce un sito? Come è possibile convincere chi prende le decisioni dell'importanza di questi interventi? Una volta ottimizzato, come si può garantire che il codice non torni a crescere inutilmente? In questo articolo vengono esaminati come convincere il management, come sviluppare una cultura delle prestazioni e un budget delle prestazioni, e vengono introdotti modi per garantire che le regressioni non si insinuino nella codebase.
- [Buone pratiche e suggerimenti per le prestazioni web](/it/docs/Learn_web_development/Extensions/Performance/Best_practices)
  - : Questo articolo tratta diversi argomenti a livello di base e fornisce collegamenti ad approfondimenti per migliorare le prestazioni per ciascun argomento. Oltre agli argomenti front-end quali HTML, CSS, JavaScript e file multimediali, tratta anche API, strumenti per sviluppatori, buone pratiche e cattive pratiche relative alle prestazioni web.
