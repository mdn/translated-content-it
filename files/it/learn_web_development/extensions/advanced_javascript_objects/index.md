In JavaScript, la maggior parte delle cose sono oggetti, dalle funzionalità fondamentali di JavaScript come gli array alle {{Glossary("API", "API")}} del browser basate su JavaScript. È inoltre possibile creare oggetti personalizzati per incapsulare funzioni e variabili correlate in pacchetti efficienti e fungere da pratici contenitori di dati.

Una conoscenza più approfondita del funzionamento degli oggetti JavaScript è utile man mano che si acquisisce sicurezza nello sviluppo web, si iniziano a creare app più complesse e si realizzano librerie personalizzate. Questo modulo sarà di aiuto fornendo teoria sugli oggetti JavaScript e pratica di programmazione orientata agli oggetti.

## Prerequisiti

Prima di iniziare questo modulo, è consigliabile aver appreso i fondamenti di [JavaScript](/it/docs/Learn_web_development/Core/Scripting), in particolare le [basi degli oggetti JavaScript](/it/docs/Learn_web_development/Core/Scripting/Object_basics). Sarebbe inoltre utile avere una certa familiarità con [HTML](/it/docs/Learn_web_development/Core/Structuring_content) e [CSS](/it/docs/Learn_web_development/Core/Styling_basics).

> [!NOTE]
> Se si lavora su un computer, tablet o altro dispositivo su cui non è possibile creare file, è possibile provare a eseguire il codice in un editor online come [CodePen](https://codepen.io/) o [JSFiddle](https://jsfiddle.net/).
