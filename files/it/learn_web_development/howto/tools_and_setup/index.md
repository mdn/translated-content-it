Questa sezione elenca le domande relative agli strumenti/software utilizzabili per creare siti web.

- [Quale software serve per creare un sito web?](/it/docs/Learn_web_development/Howto/Tools_and_setup/What_software_do_I_need)
  - : In questo articolo vengono illustrati i componenti software necessari per modificare, caricare o visualizzare un sito web.
- [Quanto costa fare qualcosa sul web?](/it/docs/Learn_web_development/Howto/Tools_and_setup/How_much_does_it_cost)
  - : Quando si lancia un sito web, è possibile non spendere nulla oppure sostenere costi molto elevati. In questo articolo si discute quanto costa ogni cosa e cosa si ottiene in cambio di ciò che si paga (o non si paga).
- [Quali editor di testo sono disponibili?](/it/docs/Learn_web_development/Howto/Tools_and_setup/Available_text_editors)
  - : In questo articolo vengono evidenziati alcuni aspetti da considerare quando si sceglie e si installa un editor di testo per lo sviluppo web.
- [Cosa sono gli strumenti per sviluppatori del browser?](/it/docs/Learn_web_development/Howto/Tools_and_setup/What_are_browser_developer_tools)
  - : Ogni browser dispone di un insieme di devtools per il debugging di HTML, CSS e altro codice web. Questo articolo spiega come usare le funzioni di base dei devtools del browser.
- [Come assicurarsi che il proprio sito web funzioni correttamente?](/it/docs/Learn_web_development/Howto/Tools_and_setup/Checking_that_your_web_site_is_working_properly)
  - : Il sito web è stato pubblicato online — ottimo! Ma si è sicuri che funzioni correttamente? Questo articolo fornisce alcuni passaggi di base per la risoluzione dei problemi.
- [Come configurare un server di test locale?](/it/docs/Learn_web_development/Howto/Tools_and_setup/set_up_a_local_testing_server)
  - : Questo articolo spiega come configurare un semplice server di test locale sul proprio computer e le basi del suo utilizzo.
- [Come caricare file su un server web?](/it/docs/Learn_web_development/Howto/Tools_and_setup/Upload_files_to_a_web_server)
  - : Questo articolo mostra come pubblicare il proprio sito online con gli strumenti {{Glossary("FTP", "FTP")}}, uno dei modi più comuni per rendere un sito web disponibile online affinché altri possano accedervi dai loro computer.
- [Come usare GitHub Pages?](/it/docs/Learn_web_development/Howto/Tools_and_setup/Using_GitHub_pages)
  - : Questo articolo fornisce una guida di base alla pubblicazione di contenuti tramite la funzionalità gh-pages di GitHub.
- [Quali strumenti sono disponibili per eseguire il debugging e migliorare le prestazioni di un sito web?](https://firefox-source-docs.mozilla.org/devtools-user/performance/index.html)
  - : Questo insieme di articoli mostra come usare gli Strumenti per sviluppatori in Firefox per eseguire il debugging e migliorare le prestazioni di un sito web, utilizzando gli strumenti per controllare l'utilizzo della memoria, l'albero delle chiamate JavaScript, il numero di nodi DOM visualizzati e altro ancora.
