## Problemi comuni e soluzioni

I seguenti collegamenti rimandano a soluzioni per problemi comuni di tutti i giorni che è necessario risolvere con HTML.

### Struttura di base

L'applicazione più elementare di HTML è la struttura del documento. Per chi è alle prime armi con HTML, questo è il punto da cui iniziare.

- [Come creare un documento HTML di base](/it/docs/Learn_web_development/Core/Structuring_content/Basic_HTML_syntax#anatomy_of_an_html_document)
- [Come dividere una pagina web in sezioni logiche](/it/docs/Learn_web_development/Core/Structuring_content/Structuring_documents)
- [Come impostare una struttura corretta di intestazioni e paragrafi](/it/docs/Learn_web_development/Core/Structuring_content/Headings_and_paragraphs)

### Semantica di base a livello di testo

HTML è specializzato nel fornire informazioni semantiche per un documento, pertanto risponde a molte domande su come trasmettere al meglio il messaggio nel documento.

- [Come creare un elenco di elementi con HTML](/it/docs/Learn_web_development/Core/Structuring_content/Lists)
- [Come dare rilievo o enfasi ai contenuti](/it/docs/Learn_web_development/Core/Structuring_content/Emphasis_and_importance)
- [Come indicare che un testo è importante](/it/docs/Learn_web_development/Core/Structuring_content/Emphasis_and_importance)
- [Come visualizzare codice informatico con HTML](/it/docs/Learn_web_development/Core/Structuring_content/Advanced_text_features#representing_computer_code)
- [Come annotare immagini e grafici](/it/docs/Learn_web_development/Core/Structuring_content/HTML_images#annotating_images_with_figures_and_figure_captions)
- [Come contrassegnare le abbreviazioni e renderle comprensibili](/it/docs/Learn_web_development/Core/Structuring_content/Advanced_text_features#abbreviations)
- [Come aggiungere citazioni e riferimenti alle pagine web](/it/docs/Learn_web_development/Core/Structuring_content/Advanced_text_features#quotations)
- [Come definire termini con HTML](/it/docs/Web/HTML/How_to/Define_terms_with_HTML)

Uno dei motivi principali per usare HTML è semplificare la navigazione con i {{Glossary("hyperlink", "collegamenti ipertestuali")}}, che possono essere usati in molti modi diversi:

- [Come creare un collegamento](/it/docs/Learn_web_development/Core/Structuring_content/Creating_links)

HTML imposta soltanto la struttura del documento. Per risolvere problemi di presentazione, usare {{Glossary("CSS", "CSS")}}, oppure usare lo scripting per rendere la pagina interattiva.

- [Come usare CSS in una pagina web](/it/docs/Learn_web_development/Core/Styling_basics/Getting_started#adding_css_to_our_document)

## Problemi non comuni o avanzati

Oltre alle nozioni di base, HTML è molto ricco e offre funzionalità avanzate per risolvere problemi complessi. Questi articoli aiutano ad affrontare casi d'uso meno comuni:

### Moduli

I moduli sono una struttura HTML complessa progettata per inviare dati da una pagina web a un server web. Si consiglia di consultare la nostra [Guida completa dedicata](/it/docs/Learn_web_development/Extensions/Forms). Ecco da dove iniziare:

- [Come creare un semplice modulo Web](/it/docs/Learn_web_development/Extensions/Forms/Your_first_form)
- [Come strutturare un modulo Web](/it/docs/Learn_web_development/Extensions/Forms/How_to_structure_a_web_form)

### Informazioni tabellari

Alcune informazioni, chiamate dati tabellari, devono essere organizzate in tabelle con colonne e righe. Si tratta di una delle strutture HTML più complesse e padroneggiarla non è facile:

- [Come creare una tabella di dati](/it/docs/Learn_web_development/Core/Structuring_content/HTML_table_basics)
- [Come rendere accessibili le tabelle HTML](/it/docs/Learn_web_development/Core/Structuring_content/Table_accessibility)

### Rappresentazione dei dati

- Come rappresentare valori numerici e di codice con HTML — vedere [Apice e pedice](/it/docs/Learn_web_development/Core/Structuring_content/Advanced_text_features#superscript_and_subscript) e [Rappresentare codice informatico](/it/docs/Learn_web_development/Core/Structuring_content/Advanced_text_features#representing_computer_code).
- [Come usare gli attributi data](/it/docs/Web/HTML/How_to/Use_data_attributes)
